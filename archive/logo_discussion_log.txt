## Solution: Update the Round Icon Design

You need to create **separate definitions** for round icons on devices that support it. Here's what to do:

### Step 1: Update the Round Icon XML (for devices that support round icons)

Create a new design structure that works better with circular masks:

```bash
# Create branch for this change
branchName: fix/adaptive-icons-round-support
```

**File:** `android/app/src/main/res/mipmap-anydpi-v26/ic_launcher_round.xml`

Replace with:
```xml
<?xml version="1.0" encoding="utf-8"?>
<adaptive-icon xmlns:android="http://schemas.android.com/apk/res/android">
    <background android:drawable="@color/ic_launcher_background_round"/>
    <foreground android:drawable="@mipmap/ic_launcher_foreground"/>
</adaptive-icon>
```

### Step 2: Add New Color for Round Background

**File:** `android/app/src/main/res/values/ic_launcher_background.xml`
