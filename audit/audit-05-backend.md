# Audit 05 — Backend

## Scope
Review server-side APIs, business logic, and security posture.

## Checklist
- Request validation (schemas, type checks)
- Authorization enforcement on every endpoint
- CSRF considerations (if cookie-based auth)
- CORS rules (least privilege origins)
- Rate limiting
- File upload/download handling
- SSRF protections (if fetching remote content)
- Idempotency and replay protection (where relevant)
- Audit logging for sensitive actions
